# Data Sheet 1 – R code

Code for: *Bayesian genomic linear–bilinear models for genotype × environment interaction improve
selection under sparse testing and scarce data* (Crossa, Vitale, Montesinos-López, Montesinos-López,
Pérez-Rodríguez, Montesinos-López and Ortiz; Frontiers in Genetics).

## Requirements

* R ≥ 4.3 (the analyses were run with R 4.6.1).
* R package **BGLR** (1.1.4 was used) for GBLUP and the reaction-norm models.
* **ASReml-R 4** (commercial licence) only for the REML FA benchmark (`reml/`).
* The Bayesian models (GSREG, GAMMI, GSREG-ESE) use only base R; the Gibbs sampler is in
  `gsreg_functions.R`.

## Model names in the code and in the paper

| Label in the code and output files | Name in the paper |
|---|---|
| `Genomic SREG K=1`, `K=2` (`specific = FALSE, main = FALSE`) | GSREG |
| `GAMMI K=1`, `K=2` (`main = TRUE`) | GAMMI |
| `Bayes genomic FA K=1`, `K=2` (`specific = TRUE`) | GSREG-ESE (= GSREG + environment-specific effects) |
| `REML FA(1)`, `REML FA(2)` | REML FA(1), REML FA(2) |
| `REML FA(2)/FA(1)` | REML FA(2), or FA(1) where FA(2) did not converge |
| `GBLUP`, `Reaction norm` | GBLUP, RN |

## Folder layout

    .                 analysis scripts; run them from this folder (outputs are written here)
    data/             load_dataset.R and the data files (see "Data")
    reml/             ASReml-R scripts of the REML FA benchmark
    reml/data/        data and partitions exported for ASReml (written by gsreg_export_for_reml.R)
    reml/results/     REML predictions (written by the scripts in reml/)

## Data

The scripts read the data with `load_dataset()` (`data/load_dataset.R`), which expects
`data/Cuevas2025/Wheat_599.rds`, `EYT_16_17.rds`, `EYT_22_23.rds` and `data/GxE/Japonica.rds`.
The original data are available from the CIMMYT Research Data & Software Repository Network
(https://hdl.handle.net/11529/10549160; Wheat 599 and the EYT trials; Cuevas et al., 2025) and from
Monteverde et al. (2019) (Japonica rice, also at https://github.com/osval78/New_GE_Framework).
The `.rds` files in the format read by `load_dataset()` are available from the corresponding author.
The simulated data (S1, S2, S3) are generated by the code from the genomic relationship matrix of
Wheat 599.

## Scripts, in the order in which they are run

Sections, tables and figures refer to the paper.

| Step | Script | What it does | Paper |
|---|---|---|---|
| – | `gsreg_functions.R` | Gibbs sampler of GSREG, GAMMI and GSREG-ESE; GBLUP and RN (BGLR); simulation scenarios; cross-validation. Sourced by the other scripts. | 2.1–2.3, 2.6 |
| 1 | `gsreg_simulation.R` | Simulation S1, S2, S3: prediction accuracy | 2.5, 3.1, Table 3 |
| 2 | `gsreg_wheat599.R`, `gsreg_run.R` | Real data: prediction accuracy (CV1, CV2, CV0) | 3.2, Table 4 |
| 3 | `gsreg_decision.R` | Selection of the top 10% and P(top 10%), 10 partitions (3 for EYT); writes `decision_<data>_lines.csv` and `_folds.csv` | 2.7 |
| 4 | `gsreg_decision_gain.R`, `gsreg_decision_summary.R` | Selection differential and calibration | 3.3, 3.5, Table 5, Figure 1 |
| 5 | `gsreg_sparse.R`, `gsreg_sparse_summary.R` | Sparse testing, k = 1, 2, 3 environments per line | 2.8, 3.4, Table 6 |
| 6 | `gsreg_biplot_wheat599.R` | Predicted GGE biplot and P(top 10%) of untested lines | 3.6, Table 7, Figure 2 |
| 7 | `gsreg_convergence.R`, `gsreg_prior_sensitivity.R` | Four chains (R̂, ESS) and prior sensitivity | 2.9, 3.7, Supplementary Figure S1 |
| 8 | `gsreg_crossover.R` | Crossover G×E from the posterior of GSREG-ESE | 2.10, 3.8, Table 8 |
| 9 | `gsreg_scarcity.R` | Data scarcity (75, 150, 300 lines; sparse_k1, unbal_50); also writes the design for ASReml | 2.11, 3.9 |
| 10 | `gsreg_export_for_reml.R` | Exports data and the exact partitions for the REML FA models | 2.7 |
| 11 | `reml/run_reml_fa.R`, `reml/run_reml_scarcity.R` | REML FA(1) and FA(2) in ASReml-R 4 on the same partitions (run from `reml/`) | 2.7, 2.11 |
| 12 | `reml_check.R`, `reml_compare.R`, `reml_precision.R` | Convergence of the REML fits and paired comparison with the Bayesian models | 3.3, 3.4, Tables 5–6 |
| 13 | `reml_scarcity_compare.R` | Data scarcity: REML FA vs. Bayesian models | 3.9, Table 9 |
| 14 | `gsreg_threshold.R` | Selection of the top 10% as a classification problem (topk, maxF1, balance); uses only the saved results of step 3 | 2.12, 3.10, Table 10 |

Each script starts with a description of its arguments and outputs. Random seeds are fixed in the
scripts, so the partitions are reproducible and identical for all models. The longest runs (step 3
for the two EYT trials) take several hours on a desktop computer.

The ASReml-R scripts in `reml/` are the versions prepared for the analysis; small adjustments may be
needed for other ASReml-R versions.
